# 管理员供应商管理

## 问题

现有每个上游账号分别维护 URL 和 API Key，缺少将同一供应商的多个 Key 归在一起管理的入口，也无法在供应商层查看共享钱包余额。

## 预期行为

- 管理员创建供应商并统一配置 URL，在详情中管理多个 Key；保存后直接出现在账号管理中，共用同一账号记录，并可绑定已有本站分组。
- 本站分组可以混用多个供应商的 Key 和自有账号；Key 名称用于区分上游分组。
- 按所有上游 Key 均不限额度的业务前提，默认自动用供应商已有 Key 查询一份共享钱包余额，无需额外配置查询来源；仍可选指定 Key 或专用查询 Key。保存 Key 后查询并支持手动刷新。
- 查询上游倍率并沿用现有可选同步及计费规则。
- 供应商新增 Key 默认开启倍率同步与池模式，并发数 100、优先级 1，允许管理员调整。
- 停用供应商阻止旗下账号参与新请求；恢复保留账号自身状态；删除供应商一并删除旗下 Key 并保留历史账务。

## 范围

包含供应商数据模型与迁移、管理员接口、账号归属与调度接入、余额查询、前端管理入口及相关验证。旧账号由管理员自行重新设置。本次不新增供应商自动定时刷新、采购充值台账或独立上游分组管理层。

详细规则见 [design.md](design.md)。
